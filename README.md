
# 💻 POOFX — CompuWorkGUI

Este proyecto es una aplicación desarrollada en **Java** con **JavaFX**


Antes de ejecutar el programa, asegúrate de tener instalado y correctamente configurado:

- **JDK 17 o superior**
- **JavaFX SDK** (descargable desde [https://openjfx.io](https://openjfx.io))
- Un entorno de desarrollo compatible, como:
  - IntelliJ IDEA
  - Eclipse
  - NetBeans (con soporte para JavaFX)
- Variables de entorno configuradas correctamente (especialmente si usas la terminal para ejecutar).

---

### ▶️ Cómo ejecutar la aplicación


1. Abre el proyecto en IDE
2. Asegúrate de tener el **SDK de Java** y el **JavaFX SDK** agregados al proyecto:
3. En la configuración de ejecución 
   - Clase principal:  
     ```
     com.ecodeup.jdbc.poofx.CompuWorkGUI
     ```
